## 🏢 Overview

**Meridian by Azertica** is an AI-powered real estate communication platform specifically designed for Dubai real estate agencies. This comprehensive dashboard and control center provides agency owners and sales teams with complete visibility and control over an intelligent AI agent that seamlessly manages:

- 📞 **Inbound & Outbound Calls** - Automated call handling with natural conversations
- 💬 **WhatsApp Conversations** - Multi-language messaging support
- 📱 **SMS Communications** - Bulk and targeted SMS campaigns
- 🌍 **Multi-Language Support** - English, Arabic, Hindi, Russian, Urdu, and more
- 🎯 **Lead Qualification** - Intelligent prospect scoring and categorization
- 📅 **Property Viewing Scheduler** - Automated booking and follow-ups
- 📊 **Visual Sales Pipeline** - Kanban-style deal management
- 📈 **Analytics & Reporting** - Comprehensive performance metrics

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/serigne007mor/fluffy-octo-guacamole.git
   cd fluffy-octo-guacamole
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   
   Navigate to [http://localhost:3000](http://localhost:3000)
